# shared/

Ce dossier est vide intentionnellement.

Il n'existe que pour signaler l'intention : si du code générique émerge
naturellement entre plusieurs agents (ex. logique de parsing de sortie IA,
gestion des retries HTTP), il sera remonté ici. Rien n'y est ajouté par
anticipation — pas avant qu'un besoin concret et partagé soit constaté entre
au moins deux agents.
